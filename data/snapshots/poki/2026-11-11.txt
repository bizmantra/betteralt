 poki.bot
 Poki keyboard
 On the native path Poki types through its own keyboard panel at a person's pace, without
reading the screen while it types. The panel has no keys and is not a keyboard for people:
it shows while Poki types and has a Take Over button. Nothing is pasted unless you choose
Paste in Advanced. See docs/poki-keyboard.md
.
 Quick start
 Poki on your iPhone
 Tell your agent:
 Install Poki on my iPhone from https://github.com/JosssphZhou/poki
 The agent follows the install-poki skill
 and runs bin/install-iphone.mjs , which does every step it can by itself. You only do what iOS asks of you: type your Apple Account into a Poki Setup window on the Mac, tap Trust and turn on Developer Mode on the iPhone, trust the developer, and open Poki. When Poki first opens it asks for Automation Mode: tap Continue and enter the iPhone passcode. If you cancel, turn Poki on again to be asked again. The agent tells you each one in a sentence when it comes up. A free Apple Account works.
 Requires macOS 14+, Node.js 24+, iOS 18+, a USB data cable, an Apple Account, and a compatible VPN/proxy app on the iPhone that routes 10.7.0.1 back to it, such as Karing or Shadowrocket configured through Poki's Setup instructions. Xcode is not required. Free Apple Account signing lasts 7 days and needs renewal. Enable UI Automation in the iPhone's Developer settings and configure model access in Poki. With an older Poki Setup and no Xcode, the agent asks you to finish model-key and connection setup manually and reports those checks as unverified until you confirm them.
 No Node.js 24, or on Windows? The same prompt works once Poki Setup is installed: the agent then uses the command line tool inside Poki Setup. Poki Setup's own menu also copies a prompt for your agent (Poki > Copy Prompt for Your Agent on a Mac, Settings > Use an agent on Windows).
 Prefer clicking through it yourself? Download Poki Setup for macOS or Windows (contributed by @ZhehanZhang
) from the Alpha release
 and follow its window.
 Poki MCP for your agent
 Let your agent install it. Copy this to your agent:
 Install https://github.com/JosssphZhou/poki following its root AGENTS.md, including the MCP skill, and stop whenever you need me to act.
 Poki MCP. Already using Claude Code, Codex, or another MCP client? Connect Poki MCP and use your own subscription. No extra model account needed.
 Start the server and keep it running:
 git clone https://github.com/JosssphZhou/poki.git
 cd
 poki
./bin/setup
npm start 
 Requires macOS 15 or later, full Xcode, Rust, Node.js 24+, and ffmpeg. ./bin/setup checks for missing dependencies. The initial build takes a few minutes.
 Poki targets macOS. For Linux, see the community port poki-for-linux
 ( #16
), maintained outside this repo.
 Poki MCP on Windows: community port at scy7796/poki-for-windows
 (maintained by its author, not tested by us).
 Prebuilt macOS arm64 package
 Download poki-v0.1.1-macos-arm64.tar.gz from the release and run:
 tar -xzf poki-v0.1.1-macos-arm64.tar.gz
 cd
 poki-v0.1.1
npm ci --no-audit --no-fund
npm start 
 The package includes the native bridge and idevice tools. You do not need Rust or ./bin/setup . You still need macOS on Apple Silicon, full Xcode, Node.js 24+, Python 3, and ffmpeg. Register your MCP client and install the optional Agent as described below.
 In another terminal, from the same directory, register the MCP server:
 claude mcp add --scope user poki-mcp -- node "
 $PWD
/src/stdio.mjs "
 #
 Claude Code
codex mcp add poki-mcp -- node "
 $PWD
/src/stdio.mjs "
 #
 Codex
 Poki Agent. For Poki's standalone terminal agent or messaging channels, keep npm start running and open another terminal in the same directory. Install the agent, add its command to this terminal's path, and sign in:
 npm ci --prefix agent
 export

poki login
poki status 
 Poki Agent uses GPT-6.1 Terra ( gpt-6.1-terra ) with low reasoning by default. We recommend keeping it: it is the fastest setup we have tested for phone tasks. Override it with POKI_AGENT_MODEL ; see Run Poki Agent
.
 For a physical iPhone, pair it with your Mac over USB first. See Physical iPhone setup
.
 Update with ./bin/poki update . Set POKI_NO_UPDATE_CHECK=1 to disable the daily anonymous GitHub release check. See Update
 for the request URL, restart steps, and prebuilt packages.
 Try a task
 With Poki Agent, one connected iPhone is selected automatically. With multiple devices, add --device '<device UUID>' .
 node bin/call.mjs list_devices #
 Find your device UUID
poki "
Search esp32 in Chrome and summarize the top result "
 Note: Poki controls your real iPhone. If you ask it to send messages or make payments, it will. Screen contents are sent to your configured model service.
 Gets faster with use: Poki Agent remembers past tasks and runs them faster on repeat.
 Channels: After configuring an authorized channel, start it with poki imessage or poki telegram 
. See Poki Agent
 for setup.
 MCP clients: Claude Code, Codex, and any client supporting mcpServers JSON.
 Physical iPhone support has been verified only on iPhones using the Chinese interface. Physical devices support portrait orientation only. App container export and direct links to Settings subpages are unavailable. See verification and known limits
.
