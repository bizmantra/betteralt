 API docs &rarr;
 python
 copy
 1
 from openai import OpenAI
 2
 client = OpenAI(
 base_url="http://localhost:8080/v1" ,
 api_key="none")
 3
 chat = client.chat.completions.create(
 model="gemma-4-e2b-it-qat-q4_0",
 messages=[{"role": "user", "content": "Hello"}])
 4
 print(chat.choices[0].message.content)
 5
 text = client.audio.transcriptions.create(
 model="whisper-1", file=open("meeting.mp3", "rb")).text
 6
 print(text) 
 Both models come from the gallery. For the second call, install whisper-1 from the gallery.

 Models and hardware
 Open models, your hardware
.
 LocalAI installs the model and downloads the backend for your CPU or GPU.
 Runs on a plain CPU. NVIDIA, AMD, Intel and Apple GPUs make it faster.
 Run it on a laptop, a server, in a container or on Kubernetes. Distributed mode spreads models over several machines.
 More than 80 backends, from llama.cpp to vLLM. We wrote 18 of them.

 Docker
 $

 # Podman works the same way
 Kubernetes
 $
 helm repo add go-skynet https://go-skynet.github.io/helm-charts/
 $
 helm install local-ai go-skynet/local-ai
 # or: kubectl apply -f https://localai.io/install/kubernetes.yaml
