 What recovery preserves 
 Crash recovery resumes an unfinished turn from recorded state. The example above shows a deliberate stop: a follow-up starts a new turn with the saved conversation and files. Cancelled runs cannot continue.
 The data directory must survive the restart. Recovery reuses recorded results for the same tool call. A newly requested tool call has a new key and may repeat an external action. Use idempotency keys or reconciliation for external actions.

 FAQ
 Frequently asked questions
 How learning works, where the savings come from, and what stays under your control.
 What does AgentRun add to my agent harness? 
 AgentRun is the platform around your chosen harness. Define agents, run them through a common API, and manage their revisions, run history, recovery, and learning in one place. The harness still handles the agent’s reasoning and tool use.
 Explore the platform
 Is AgentRun open source? How does it relate to Grep? 
 AgentRun is open source under Apache-2.0, built by the team behind Grep. Learning, recovery, and the console are included. You can self-host with your own model API keys; model and infrastructure costs are yours. Grep is our managed platform for business agents. AgentRun Cloud is our hosted AgentRun offering, and is optional when you self-host.
 AgentRun on GitHub
 · About Grep
 How does self-learning work? 
 When learning is enabled, the agent reflects on its runs and proposes notes, reusable skills, and workflow drafts. Accepted changes are versioned and available to later runs, so repeated steps can be reused instead of planned again. This updates the agent’s saved knowledge and procedures, not the model’s weights.
 How learning works
 How does that reduce token usage? 
 An agent can spend tokens rediscovering an API, planning the same request, or deciding how to validate a result. Reusing a skill or workflow can skip that repeated reasoning. The agent still uses models and tools where needed. Potential savings come from reducing repeated work.
 Reusable skills and workflows
 How much will I save? 
 Savings depend on how much work repeats. The launch post reported a 90% cost reduction for one compliance workload. Results vary, and reflection and grading also add cost. Measure total spend and answer quality on your own workload, including the cost of learning.
 Launch example

 What happens when a decision is uncertain? 
 You define the threshold and the fallback in your workflow. Uncertain results can go to an agent for further investigation or trigger escalation for review. A confidence score is a routing signal, not a guarantee of accuracy. Choose thresholds using evaluated examples and the consequences of getting the decision wrong.
 Confidence and fallback
 · Interpreting scores
 Do I need Jev to use AgentRun? 
 No. Jev is an optional integration for focused decisions in workflows you author, such as choosing a category or returning a score. Agents and self-learning work without it. Automatically learned workflows currently use supported model and tool steps; they do not automatically turn into Jev decisions.
 Jev integration
 · Learned workflow support
 Do I have to turn my whole agent into a workflow? 
 No. Keep open-ended tasks agentic and make repeatable steps reusable. Workflows can include agent investigation at defined points, so you can automate routine paths while deciding how exceptions should be handled. You control where a workflow continues, retries, or asks for help.
 See a workflow with agent investigation
 How are learned changes checked? 
 Proposals pass structural checks and an AI grader before they can be reused. Changes that widen trust, loosen checks, or direct money or data require owner approval. You can inspect changes, edit notes, or retire learned material. These checks help filter proposals; you still need to evaluate results on your tasks.
 Validation and approval
 Which harnesses can I use? 
 Pi, Claude Code through the Claude Agent SDK, Codex, and OpenCode. Choose a harness in your AgentRun agent definition while keeping shared run management and learning. Each harness needs its own configuration, and available models and tools can differ.
 Harness setup
 Can I run AgentRun on my own infrastructure? 
 Yes. Self-host the open-source platform locally or on your own server and bring your model API keys. Agent definitions, runs, and learned material live in your configured data directory. Model calls and hosted browser sessions still go to the providers you configure.
