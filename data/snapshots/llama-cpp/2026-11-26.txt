 Description
 The main goal of llama.cpp is to enable LLM (and MLLM) inference with minimal setup and state-of-the-art performance on a wide range of hardware - locally and in the cloud.
 The llama.cpp project is built on top of the ggml
 library.
 Quick start
 A few options to get llama.cpp installed on your machine:
 #
 curl
curl -LsSf https://llama.app/install.sh |
 sh
 #
 powershell
irm https://llama.app/install.ps1 |
 iex 
 Visit https://llama.app
 and follow the instructions
 Run with Docker - see our Docker documentation
 Download pre-built binaries from the releases page
 Build from source by cloning this repository - check out our build guide
 Once installed:
 #
 Download and run a model directly from Hugging Face
llama cli -hf ggml-org/Qwen3.5-0.8B-GGUF
 #
 Launch OpenAI-compatible API server
llama serve -hf ggml-org/Qwen3.5-0.8B-GGUF 
 VLM session with llama cli 
 Llama Chat, the built-in chat app, against llama serve
