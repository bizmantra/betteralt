 Design the layout
 Edit desktop and phone layouts side by side. A change on one canvas shows up on the others, so you can see where a layout needs an adjustment.

 Questions about Instatic
 What is Instatic?
 Instatic is an open-source visual CMS you run on your own server. You design the site and define its content. Your agent can work on the same pages and data through MCP or the CLI, and you can add custom features with plugins.
 Is Instatic free?
 Yes. The CMS is free and MIT licensed. The visual editor, collaboration, branches, built-in agent, MCP server and CLI are all included.
 What does Instatic Pro add?
 Pro includes Instatic Desktop for macOS and Windows, 38 templates, the section library and support tickets. Official plugins are included as they ship. Choose Pro for one person or Team for three or more seats.
 Where can I run it?
 Deploy to Railway in one click, or run the Docker image on a host you choose. Instatic stores your content in SQLite or Postgres and keeps uploaded files on your server.
 Can I build a members-only site?
 Yes. Members can sign in with a password or an emailed link. You can restrict pages by access tag and show each person their own content. On this site, customers use their account to find downloads and check support tickets.
 Can my team edit together?
 Yes. You can edit a page with someone else and see their cursor and selection. For changes you want to review first, work on a branch and share a preview link before merging.
 Can I bring the site I already have?
 Yes, if you have the static files. Super Import brings the HTML, CSS, images and fonts into the editor. You can review conflicts before it creates any pages.
 How can my agent work on the site?
 Use the built-in agent with your own model, or connect an external agent through MCP or the CLI. MCP lets the agent work in your open editor. The CLI uses a service account to call the CMS API directly. Your agent can create a branch, edit a page and test the result while the editor is closed.
